# Surpryze MVP

This repository implements the first end-to-end milestone:

**Playwright suite → learn (Assumption Graph) → experiments → Playwright execution → surprise → report**

`surpryze learn` writes `.surpryze/assumption-graph.json` and prints weakest assumptions first. Use `surpryze graph --json` for agent consumption.

See the root [README](../README.md) for commands and the demo password-reset scenario under `examples/`.
