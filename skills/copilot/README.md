# GitHub Copilot skills

Copilot discovers agent skills from `.github/skills/<name>/` (project) or `~/.copilot/skills/<name>/` (personal).

From this repository, install Surpryze:

```bash
cp -r skills/copilot/surpryze .github/skills/surpryze
```

Or copy to `~/.copilot/skills/surpryze` for all projects.

The Claude/Cursor-oriented copy lives in [`../surpryze/SKILL.md`](../surpryze/SKILL.md).
